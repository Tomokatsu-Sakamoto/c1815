> トランジスタ静特性 リアルタイム測定妥当性検証システム

学校教育、工業高校、大学、高専の電気・電子系実習における「トランジスタ（2SC1815等）の静特性測定実験」のデータをその場で即時グラフ化し、物理法則の観点から測定データの矛盾をリアルタイムに診断・検証するためのWebアプリケーションです。

## 🛠️ 主な機能と特長

1. **一元化された4つの静特性検証**

   * **出力特性 (**$V_{CE} - I_C$**)**: $I_B$ を代表的な4ステップ（$20, 40, 60, 80\,\mu\text{A}$）に設定し、それぞれコレクタ電圧10測定点に対するコレクタ電流 $I_C$ の関係を正確な数値比例スケール（X軸：線形リニア）で描画します。

   * **伝達特性 (**$I_B - I_C$**)**: 入力ベース電流に対するコレクタ電流の関係を描画し、電流増幅率 $h_{FE}$ の線形性を検証します。

   * **入力特性 (**$V_{BE} - I_B$**)**: 低電流域（電圧指定）と高電流域（電流固定）のハイブリッド測定（実習書準拠）を完全サポート。全9座標の自動昇順ソート機能により、MathJax数式対応の最小二乗法「指数近似曲線」を美しくグラフ上にフィッティングさせます。

   * **直流負荷線 (**$E_C = 9.0\text{V}, R_C = 390\,\Omega$**)**: キルヒホッフ・オームの法則に基づく理論負荷線を $(9.0\text{V}, 0\text{mA})$ で精密カット描画。実測データとの偏差を自動検証します。

2. **インテリジェント物理妥当性検証 (リアルタイム診断)**

   * **単調増加チェック**: 電圧・電流の増加に対し、物理的にあり得ない数値の「減少（逆転）」が発生した瞬間に入力セルを警告色にし、矛盾点をテキストで警告します。

   * $h_{FE}$ **(直流電流増幅率) ランク自動判定**: 伝達特性データから動作領域の $h_{FE}$ を自動算出し、2SC1815の標準ランク区分（O / Y / GR）に自動フィッティングさせて適合率を可視化します。

   * **近似物理式の算出**: 入力特性のグラフ上に、最小二乗モデルより得られた順方向ダイオード近似式 $I_B = a \cdot e^{b \cdot V_{BE}}$ を自動計算して画面上に表示します。

3. **レポート作成に抜群のユーティリティ**

   * **UTF-8 BOM付きCSV保存**: 実測されたデータを、Excel等で開いても絶対に文字化けしないBOM付きのCSVファイル形式として「個別保存」または「一括保存」が可能です。

   * **グラフ画像ダウンロード**: Chart.jsで生成された高精細なグラフをワンクリックでPNG画像としてPCに保存し、そのままWordなどのレポートに貼り付けられます。

   * **Y軸自動最適化(オートスケーリング)**: 入力値の最高値に合わせて、最もグラフが端正に見えるようY軸目盛りを自動スケーリングします。

## 🌐 GitHub Pagesでの公開手順（無料公開）

このプロジェクトをGitHubにアップロードし、全世界にWebサイトとして公開する手順は驚くほど簡単です。

### ステップ 1: GitHubでリポジトリを作成する

1. [GitHub](https://github.com/)にログインします（アカウントが無い場合は作成します）。

2. 右上の「**+**」ボタン ＞「**New repository**」をクリックします。

3. **Repository name** に適当な名前（例: `transistor-analyzer`）を入力します。

4. **Public**（公開）にチェックが入っていることを確認します。

5. 「**Create repository**」をクリックしてリポジトリを作成します。

### ステップ 2: ファイルをアップロードする

1. 作成後の画面にある「**uploading an existing file**」というリンクをクリックします。

2. 本レポジトリの `index.html` と `README.md` のファイルをドラッグ＆ドロップします。

3. 画面下部の「**Commit changes**」ボタンをクリックしてコミット（保存）します。

### ステップ 3: GitHub Pagesを有効化する

1. アップロード完了後、リポジトリ上部のメニューバーから「⚙️ **Settings**（設定）」をクリックします。

2. 左メニューの「**Code and automation**」グループにある「**Pages**」をクリックします。

3. **Build and deployment** セクション of **Branch** にあるプルダウンを `None` から `main` (または `master`) に切り替え、右横のフォルダ選択が `/ (root)` になっていることを確認して「**Save**」をクリックします。

### ステップ 4: 公開完了！

1. 数十秒待ってページをリロード（再読み込み）すると、Pages設定の最上部に、
   `Your site is live at https://<あなたのユーザー名>.github.io/<リポジトリ名>/`
   というURLが表示されます。このURLをクリックすれば、あなたのWebアプリが動作します！
